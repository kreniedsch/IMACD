# IMACD

Web-App für IMACD-Techniker: Tickets fotografieren oder einfügen, Fix-/Flex-Termine erkennen und den Tagesablauf automatisch planen.

**App öffnen:** https://kreniedsch.github.io/imacd/

- Ticketblätter per Kamera, PDF, Outlook-Text oder .ics erfassen
- Filter für Techniker 1–3
- Fixtermine immer sichtbar, Flex-Tickets automatisch eingeplant
- Optional: KI-Erkennung mit Claude (eigener API-Key)
- Backup-Export/-Import (.json)

Daten bleiben lokal auf dem Gerät.
